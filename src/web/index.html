忘记密码？用环境变量密码进门
  1. 打开 Cloudflare Dashboard → Workers & Pages → cdt-worker → Settings → Variables and Secrets
  2. 新增一个变量：名称 ADMIN_PASSWORD，值填你的恢复密码，类型选 Secret（建议至少 12 位）
  3. 点 Deploy / Save and deploy 让变量生效（约 30 秒）
  4. 回到本页，直接输入这个恢复密码登录 —— 登录成功后系统管理员密码会同步为该值，随后可在「设置 → 管理员密码」里改成新密码

该变量长期保留可当作兜底入口；若不再需要，在 Cloudflare 删除它即可，删除后仅 D1 中的密码有效。

建议使用 12 位以上，混合大小写、数字与符号

RAM 账号最小权限

建议为本系统创建专用 RAM 用户并只授予下方 6 个权限，避免使用主账号 AccessKey

创建专用 RAM 用户（约 2 分钟）
  1. 打开阿里云控制台 → 访问控制 RAM → 身份管理 → 用户 → 创建用户，勾选「OpenAPI 调用访问」
  2. 创建完成后复制生成的 AccessKey ID / Secret（Secret 只显示一次），填到下方表单
  3. 在该用户详情页 → 权限管理 → 新增授权 → 自定义策略 → 粘贴下方 JSON
  4. 不启用账单功能时，可从策略中删去两条 bss: 权限，进一步收窄
每个权限的用途
  1. cdt:ListCdtInternetTraffic — 读取 CDT 互联网流量明细（核心监控数据）
  2. ecs:DescribeInstanceStatus — 读取实例运行状态
  3. ecs:StartInstance / ecs:StopInstance — 阈值自动停机与保活开机
  4. bss:QueryAccountBalance / bss:DescribeInstanceBill — 账户余额与实例账单（可选功能）

定时监控配置

本项目未使用 Cloudflare Cron（免费账号仅 5 个），改用外部定时服务触发

监控触发地址

把这个地址填到任意外部定时服务里，按上面的「监控间隔」周期性请求即可。

方式一 · cron-job.org（推荐，免费无需信用卡）
  1. 打开 cron-job.org 注册并登录
  2. Cronjobs → 右上角 Create cronjob 新建任务
  3. URL 粘贴上面的「监控触发地址」
  4. 执行计划选择「每 N 分钟」，N 与上方「监控间隔」保持一致
  5. 保存后即开始周期触发
方式二 · GitHub Actions（已有 GitHub 账号）
  1. 在代码仓库新建 .github/workflows/cron.yml（用下方代码块）
  2. 推送后每 5 分钟自动请求一次触发地址
方式三 · UptimeRobot（免费，顺带做可用性监控）
  1. 打开 uptimerobot.com 注册并登录
  2. New monitor → 类型选 HTTP(s)
  3. URL 粘贴上面的「监控触发地址」
  4. 监控间隔选「5 分钟」（与监控间隔一致）
  5. Create monitor 保存

临时验证：也可以直接在浏览器打开触发地址，或点右上角「立即监控一次」。

  2. 新增变量 ADMIN_PASSWORD，值填恢复密码，类型建议 Secret
  3. Save and deploy 生效后，用该密码登录即可进入系统（密码会自动同步为它）
