定时监控配置

本项目不使用 Cloudflare 自带 Cron（免费额度仅 5 个），改用外部定时服务请求下面的触发地址，实现每 N 分钟自动监控。

方式一：cron-job.org（推荐，免费无需信用卡）
  1. 打开 cron-job.org 注册并登录
  2. 新建任务（Create cronjob），URL 填上面的「监控触发地址」
  3. 调度间隔填 5 分钟（与上方「监控间隔」保持一致）
  4. 保存即可，之后会每 5 分钟自动监控一次
方式二：GitHub Actions（已有 GitHub 账号可用）
  1. 在代码仓库新建文件 .github/workflows/cron.yml
  2. 内容填入：schedule: - cron: '*/5 * * * *'，执行 curl -s "上面的触发地址"
  3. 提交推送，GitHub 会每 5 分钟自动请求一次
方式三：UptimeRobot（免费，还能顺带做可用性监控）
  1. 打开 uptimerobot.com 注册并登录
  2. 新建监控（New monitor），类型选 HTTP(s)
  3. URL 填上面的「监控触发地址」，监控间隔选 5 分钟
  4. 保存即可，之后会每 5 分钟请求一次

也可以手动触发：直接点击上面的地址在浏览器打开，或点下方按钮立即执行一轮监控。
