# 修复方案（2026-09-27）——基于 `docs/audit-2026-09-27.md`

原则：**最小改动、可回滚、按风险分波次**；每波结束都必须跑 `npm test` + `tsc --noEmit`，并按约定推送 GitHub。
额度策略：**优先砍 CPU 与无谓写操作**，不牺牲监控频率（当前额度占用 <7%，无需降频）。

---

## Wave 1 · 安全与一致性必修（B1 / W1 / W2）

| 项 | 改动 | 文件 |
| --- | --- | --- |
| B1 | 删除 `init-status` 返回的 `envPasswordSet` 字段 | `src/http/server.ts` |
| W1 | 会话鉴权 + 非安全方法校验 `X-CDT-CSRF` 与 `cdt_csrf` cookie（常量时间比较）；API Key 路径不校验 | `src/http/server.ts` |
| W2 | 登录失败先 COUNT `login_attempts`（15 分钟窗口）再决定是否 429；登录成功清理该 IP 记录；保留内存限流作第一道 | `src/http/server.ts` |

**风险**：W1 若前端有遗漏未带 header 的写请求会 403 —— 前端统一走 `apiJson` 已带该头，且刷新后从 cookie 恢复，风险低；上线后观察日志页 403 记录。

**验收**：
- 未登录访问 `/api/v1/system/init-status` 响应只有 `initialized`
- 登录后不带 `X-CDT-CSRF` 的 POST 返回 403；带正确头正常
- 连续 9 次错误密码 → 第 9 次 429（跨 isolate 生效，可本地 `wrangler dev` 两次请求验证）

## Wave 2 · CPU 与额度优化（W5 / W6 / W7 / S1 / S2）

| 项 | 改动 | 预期收益 |
| --- | --- | --- |
| W5 | `src/engine/time.ts` 增加 `Intl.DateTimeFormat` 模块级缓存（按 timezone 复用），`toZone`/`zoneFields` 改用缓存实例 | 每周期省 20–30 次格式化器构造，**单请求 CPU 下降最明显的一项** |
| W6 | `touchTriggerSource(env, source, now, seen)` 接收已读 state，避免二次读；`checkTriggerGaps` 复用同一次读取 | 每触发少 2 次 D1 读；消除 `trigger_seen` 读-改-写覆盖 |
| W7 | `deleteActionEvent(thresholdKey)` 改为条件执行（本周期记录过才删） | 每周期省约 5 次 DELETE |
| S1 | heartbeat 日志：仅在「状态变化 / 产生动作 / 距上次心跳 ≥ 15 分钟」时写入 | 每天少约 1,000–1,400 次写 |
| S2 | 过期数据清理改为每天一次（`action_events` 键 `cleanup:YYYYMMDD` 去重） | 每周期少 2–4 次查询 |

**风险**：W5 涉及时区核心逻辑 —— 必须保证单测覆盖（`time-window.test.ts` 已有 17 例），改后全绿即安全。
**验收**：`npm test` 全绿；生产观察 `/__cron` 的 CPU 时间（Dashboard → Workers → 该请求 Metrics）。

## 建议不做（明确列为技术债，不进本次迭代）

| 项 | 原因 |
| --- | --- |
| 加密补 AAD（S4） | 需版本化迁移存量密文，收益中等、风险偏高，列为演进项 |
| 删除 `jobs` 死表（S7） | 仅影响新库建表，无运行时收益，收益 < 改动风险 |
| 降低监控频率省额度 | 当前额度占用 <7%，降频反而牺牲监控实时性，不划算 |

## 额度保障清单（部署后逐项确认）

1. **Dashboard → Workers → cdt-worker → Triggers**：确认无残留 Cron 触发器（免费额度仅 5 个）
2. **Dashboard → Workers → Metrics**：抽查 `/__cron` 单次 CPU 时间，目标 < 10ms
3. **D1 → cdt-monitor-db → Metrics**：行读取/写入日趋势（预期远低于 5M / 100k）
4. **日志保留天数**：建议 7–14 天（默认 30 天，省存储）
5. **通知通道**：确认没有把 `heartbeat` 类事件也发出去（当前只有阈值/保活/定时三类）
